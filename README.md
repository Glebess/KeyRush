# ⌨️ KeyRush — Тренажер скорости печати

Веб-приложение для тренировки и проверки скорости печати на клавиатуре с поддержкой личных кабинетов, сохранения результатов и детальной статистики.

---

## Стек технологий

- **Фронтенд:** React, TypeScript / JavaScript, React Router DOM, CSS Modules
- **Бэкенд:** Node.js, Express.js
- **База данных:** SQLite, `sqlite3`
- **Безопасность:** `bcrypt` (хэширование паролей)
- **Инструменты:** CORS, Git

---

## Основные функциональные возможности

1. **Тренажер печати:**
   - Измерение скорости (WPM — слов в минуту).
   - Расчет точности ввода (`accuracy`).
2. **Система аутентификации:**
   - Регистрация новых пользователей с безопасным хэшированием паролей (`bcrypt`).
   - Авторизация и управление сессией.
3. **Динамические профили:**
   - Страница профиля каждого пользователя доступна по его уникальному имени (`/profile/:username`).
   - Отображение даты регистрации и агрегированной статистики (всего тестов, время печати).
4. **Обработка ошибок:**
   - Страница **404 (Not Found)** для несуществующих пользователей и маршрутов.

---

## Установка и запуск проекта

Для запуска проекта у вас должен быть установлен [Node.js](https://nodejs.org/).

### 1. Клонирование репозитория

```bash
git clone <ссылка-на-ваш-репозиторий>
cd <название-папки-проекта>
```

### 2. Запуск Бэкенда

```bash
# Установка зависимостей бэкенда
npm install

# Запуск сервера (порт 5000)
node index.js
# или если используется nodemon:
npm run dev
```

### 3. Запуск Фронтенда

```bash
# Установка зависимостей фронтенда
npm install

# Запуск клиента (обычно порт 5173 или 3000)
npm run dev
```
